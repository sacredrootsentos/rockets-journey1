# Rocket's Big Journey — Interactive Companion

Published by Wild & Rooted Co.

## Files

- `index.html` — the entire app. One file, no dependencies.
- `header.png` — optional banner image shown above the title.

## Adding the header image

Name your image **`header.png`** exactly, and upload it into this same folder
alongside `index.html`. That's it — it appears automatically.

If the file isn't there, the app still works perfectly. It just shows the
paw-print icon instead. Nothing breaks.

Recommended: 1600 × 400 pixels (4:1 ratio), PNG or JPG, under 500 KB.
If you use a `.jpg`, either rename it to `header.png` or edit the one
`src="header.png"` line near the top of `index.html`.

## Updating

Edit `index.html`, commit, and GitHub Pages republishes within a minute or two.
